# negi

MikuOS's desktop shell config: a fork of **end4-pC** by pctrade
(https://github.com/pctrade/end4-pC, revision `009cec4`), itself a fork of
end-4's illogical-impulse dots. It runs on aosh, MikuOS's QML shell, as
`aosh -c negi`.

Everything in this directory is upstream's and stays under upstream's licence,
the GNU GPL version 3 (`LICENSE`). The rest of the MikuOS tree is Apache-2.0;
aosh interprets these files and does not link them.

Every line changed from upstream carries a `// MikuOS:` comment with the
reason. The list of those changes, by file, is kept in the MikuOS tree's
`dev/aosh-negi.md` under "Edits", so an update from upstream is a copy, a
diff, and that list replayed.
